## 1. Problem Formulation & Motivation

GPS observations from vehicle telematics suffer from multipath reflection, signal scattering, sensor noise, and discrete temporal sampling. A raw GPS trajectory is a sequence of discrete spatial coordinates:
$$Z = (z_0, z_1, \dots, z_{T-1}), \quad z_t = (\text{lon}_t, \text{lat}_t, t_t)$$

Independent pointwise candidate classification (selecting the arc $\arg\max_a P(a \mid z_t)$ independently at each observation) fails because:
1. **Topological Discontinuity:** Spatially proximal candidate arcs may belong to disconnected roads, dead ends, or opposing one-way lanes.
2. **Sensor Reflection / Noise Jumps:** A single noisy GPS reading can cause the route to zigzag across parallel highways or cross streets, creating artificial route breaks.
3. **Temporal Infeasibility:** Transitions between consecutive chosen arcs may imply impossible vehicle speeds or reverse travel on directed one-way edges.

The **Hidden Markov Model (HMM) with Viterbi decoding** resolves this by modeling trajectory map-matching as a global sequence optimization problem over the directed road network graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$.

---

## 2. HMM Mathematical Architecture

```
Observations:    z_0              z_1              ...              z_{T-1}
                  │                │                                  │
                  ▼                ▼                                  ▼
States:          s_0 ────────────> s_1 ────────────> ... ──────────> s_{T-1}
                 a_{0,i}          a_{1,j}                           a_{T-1,k}
```

- **Observations $z_t$:** GPS measurements (longitude, latitude, timestamp).
- **Hidden States $s_t \in S_t$:** The candidate directed road arcs $S_t = \{a_{t,1}, a_{t,2}, \dots, a_{t,K_t}\}$ generated by Member 1 within search radius $R = 250\text{m}$.
- **Emission Probability $P(z_t \mid a_{t,i})$:** The likelihood that candidate road arc $a_{t,i}$ produced GPS observation $z_t$.
- **Transition Probability $P(a_{t,j} \mid a_{t-1,i})$:** The probability of moving from candidate arc $a_{t-1,i}$ to candidate arc $a_{t,j}$, conditioned on directed road network topology and travel feasibility.

---

## 3. Emission Probability Formulation

Candidate probabilities $P(a_{t,i} \mid \mathbf{x}_{t,i})$ are computed by any of the five candidate classification models:
1. Logistic Regression
2. K-Nearest Neighbours (KNN)
3. Random Forest (RF)
4. LightGBM (LGBM)
5. Multi-Layer Perceptron (MLP)

To prevent numerical underflow and ensure compatibility with dynamic programming:
$$p'_{t,i} = \frac{p_{t,i}}{\sum_{k=1}^{K_t} p_{t,k} + \epsilon}$$
$$\log E(z_t \mid a_{t,i}) = \log(\max(p'_{t,i}, \epsilon))$$
where $\epsilon = 10^{-7}$ provides numerical stability against zero, missing, or negative probabilities.

---

## 4. Transition Scoring over Directed Networks

Transition scores are formulated following the Newson & Krumm (2009) exponential decay model adapted to directed multi-graphs:
$$\text{Transition Score}(a_{t-1,i} \to a_{t,j}) = -\frac{|d_{\text{net}}(a_{t-1,i}, a_{t,j}) - d_{\text{gps}}(z_{t-1}, z_t)|}{\beta}$$

Where:
- $d_{\text{gps}}(z_{t-1}, z_t)$: Great-circle / WGS84 geodesic distance between consecutive GPS observations in metres (using `pyproj.Geod`).
- $d_{\text{net}}(a_{t-1,i}, a_{t,j})$: Shortest path distance along directed edges in the road graph from arc $a_{t-1,i}$ to arc $a_{t,j}$ in metres.
- $\beta$: Configurable distance deviation scaling parameter in metres (default: $\beta = 30.0\text{m}$).

### Network Distance Calculation ($d_{\text{net}}$):
Let $u_{\text{end}} = \text{to\_node}(a_{t-1,i})$ and $v_{\text{start}} = \text{from\_node}(a_{t,j})$.
With candidate projection ratios $p_{t-1}, p_t \in [0, 1]$:
1. **Same Arc ($a_{t-1,i} == a_{t,j}$):**
   - Forward motion ($p_t \ge p_{t-1}$): $d_{\text{net}} = (p_t - p_{t-1}) \cdot \text{length}(a_{t-1,i})$.
   - Backward motion on one-way road ($p_t < p_{t-1}$): Vehicle must loop around: $(1 - p_{t-1})\text{len}_1 + d_{\text{Dijkstra}}(u_{\text{end}}, v_{\text{start}}) + p_t \text{len}_2$.
2. **Directly Connected Arcs ($u_{\text{end}} == v_{\text{start}}$):**
   $$d_{\text{net}} = (1 - p_{t-1}) \cdot \text{length}(a_{t-1,i}) + p_t \cdot \text{length}(a_{t,j})$$
3. **Multi-Hop Path ($u_{\text{end}} \neq v_{\text{start}}$):**
   $$d_{\text{net}} = (1 - p_{t-1}) \cdot \text{length}(a_{t-1,i}) + d_{\text{Dijkstra}}(u_{\text{end}}, v_{\text{start}}) + p_t \cdot \text{length}(a_{t,j})$$
4. **Unreachable Transitions:**
   If no directed path exists between $u_{\text{end}}$ and $v_{\text{start}}$ in $\mathcal{G}$, return $\text{unreachable\_penalty} = -10000.0$.

## 5. Viterbi Dynamic Programming Algorithm

Dynamic programming is computed in log-space:

### Initialization ($t = 0$):
For each candidate $i \in \{0, \dots, K_0 - 1\}$:
$$V_0(i) = \log E(z_0 \mid a_{0,i})$$
$$B_0(i) = -1$$

### Recurrence ($t = 1, \dots, T-1$):
For each candidate $i \in \{0, \dots, K_t - 1\}$:
$$V_t(i) = \max_{j \in \{0, \dots, K_{t-1}-1\}} \left[ V_{t-1}(j) + \text{Transition Score}(a_{t-1,j} \to a_{t,i}) \right] + \log E(z_t \mid a_{t,i})$$
$$B_t(i) = \arg\max_{j \in \{0, \dots, K_{t-1}-1\}} \left[ V_{t-1}(j) + \text{Transition Score}(a_{t-1,j} \to a_{t,i}) \right]$$

### Termination:
$$i^*_{T-1} = \arg\max_{i} V_{T-1}(i)$$
$$\text{Log-Likelihood} = \max_{i} V_{T-1}(i)$$

### Backtracking ($t = T-2, \dots, 0$):
$$i^*_t = B_{t+1}(i^*_{t+1})$$

The decoded sequence of candidate arcs is:
$$A^* = (a_{0, i^*_0}, a_{1, i^*_1}, \dots, a_{T-1, i^*_{T-1}})$$

## 6. Continuous Route Reconstruction

Viterbi selects candidate arcs at observation timestamps. When sampling frequency is coarse (e.g. 1 Hz to 0.1 Hz) or vehicles travel quickly, consecutive observations skip intermediate connecting road segments.

`src/route_reconstruction.py` transforms the observation-level arcs into a complete, gap-free directed route:
1. **Consecutive Same Arc:** Maintained as ongoing traversal without artificial duplicates.
2. **Direct Connection ($u_{\text{end}} == v_{\text{start}}$):** Appends destination arc.
3. **Multi-Hop Traversal ($u_{\text{end}} \neq v_{\text{start}}$):**
   - Calls `RoadNetwork.shortest_path(u_{\text{end}}, v_{\text{start}})`.
   - Iterates through the returned node sequence $[n_0, n_1, \dots, n_k]$.
   - Retrieves the optimal directed edge key for each pair $(n_i, n_{i+1})$, selecting the minimum length arc when parallel edges exist.
   - Inserts all intermediate arcs in chronological order.
4. **Legitimate Loops:** Preserved at their true temporal positions (no global deduplication).
5. **Route Discontinuities:** Where no directed path exists, a `RouteGap` is logged, and downstream reconstruction continues.

## 7. Worked Numerical Example

Consider 2 GPS observations $z_0, z_1$ spaced $100\text{m}$ apart ($d_{\text{gps}} = 100\text{m}$):
- $z_0$ candidates:
  - Arc 0: $\text{length} = 100\text{m}$, emission prob = $0.40$ ($\log E = -0.916$)
  - Arc 5 (cross street): $\text{length} = 120\text{m}$, emission prob = $0.90$ ($\log E = -0.105$)
- $z_1$ candidate:
  - Arc 1 (connected downstream of Arc 0): $\text{length} = 100\text{m}$, emission prob = $0.80$ ($\log E = -0.223$)

Transitions with $\beta = 30.0\text{m}$:
1. **From Arc 0 to Arc 1:**
   Directly connected junction ($u_{\text{end}} == v_{\text{start}}$).
   $d_{\text{net}} = 0.5 \times 100 + 0.0 + 0.5 \times 100 = 100\text{m}$.
   $\Delta d = |100 - 100| = 0\text{m}$.
   $\text{Transition Score} = -0 / 30 = 0.0$.
   Total Path Score = $-0.916 + 0.0 - 0.223 = \mathbf{-1.139}$.

2. **From Arc 5 to Arc 1:**
   Arc 5 is a parallel dead-end with no directed connection to Arc 1.
   $\text{Transition Score} = -10000.0$.
   Total Path Score = $-0.105 - 10000.0 - 0.223 = \mathbf{-10000.328}$.

**Decision:**
- Top-1 Baseline chooses Arc 5 at $z_0$ (prob 0.90) $\to$ Disconnected break!
- HMM/Viterbi chooses Arc 0 at $z_0$ $\to$ Valid connected route!
